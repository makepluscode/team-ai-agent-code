# 02-organize-notes: 뒤섞인 회의 노트·업무 노트 한 번에 정리하기

이름이 제각각인 회의 노트, 업무 노트, 메신저 대화 내보내기, 메신저로 받은 사진 12개를 헤르메스가 읽고 정리 규칙에 따라 날짜로 시작하는 이름의 복사본으로 정리하는 예제입니다. 원본은 그대로 둡니다. 책 2.2절에 대응합니다.

## 실행 방법

```bash
cd ~/team-ai-agent/code/ch02/02-organize-notes
hermes chat --query-file prompt.md
uv run check.py
```

헤르메스가 대응표를 먼저 보여 주면 근거를 읽어 보고 "확인했어. 정리해 줘"처럼 답합니다. 정리가 끝나면 `/exit`로 나와 check.py를 실행합니다.

처음부터 다시 할 때는 이 폴더에서 `uv run reset.py`를 실행해 결과 폴더(output/)를 지운 뒤 실행 방법을 다시 따라 합니다. 헤르메스 설정(~/.hermes)은 바뀌지 않습니다. 원본(input/files/)이 바뀌었으면 `git restore input`으로 받은 상태로 되돌리고, 직접 넣은 내 파일은 따로 지웁니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| prompt.md | 정리 규칙과 진행 순서를 담은 지시문 |
| input/files/ | 정리할 원본 12개(합성 자료). 수정하지 않습니다 |
| output/organized/ | 정리본(실행하면 생깁니다). 이름순이 날짜순입니다 |
| output/source-map.json | 원래 이름·정리본·상태·근거를 담은 대응표(헤르메스가 저장) |
| expected/source-map.json | 편집한 비교용 대응표와 원본 해시 |
| check.py | 원본 보존, 정리본 바이트 일치, 이름 형식과 날짜, 중복·확인 필요 처리를 확인합니다 |
| reset.py | 결과 폴더(output/)를 지워 처음부터 다시 하기. ~/.hermes는 바꾸지 않습니다 |

이름의 주제 부분(예: 주간회의, 할일)은 실행마다 표현이 달라도 됩니다. check.py는 날짜·형식·내용 일치만 확인하고, 종류와 주제가 알맞은지는 사람이 대응표로 판단합니다.
