# 02-organize-notes: 뒤섞인 회의 노트·업무 노트 한 번에 정리하기

> 이 예제는 윈도우의 헤르메스 데스크톱 앱으로 실습합니다. 예제는 홈 폴더의 team-ai-agent\code(C:\Users\로그인 이름\team-ai-agent\code)에 받고, 대화창에 넣을 문장은 [복사용 문장 모음](../../COMMANDS.md)에서 복사합니다. 헤르메스 설정 폴더는 C:\Users\로그인 이름\AppData\Local\hermes입니다.

이름이 제각각인 회의 노트, 업무 노트, 메신저 대화 내보내기, 메신저로 받은 사진 12개를 헤르메스가 읽고 정리 규칙에 따라 날짜로 시작하는 이름의 복사본으로 정리하는 예제입니다. 원본은 그대로 둡니다. 책 2.2절에 대응합니다.

## 실행 방법

새 대화에서 다음 문장을 보냅니다.

```text
작업 폴더는 홈 폴더의 team-ai-agent\code\ch02\02-organize-notes야. 이 폴더의 prompt.md를 읽고 그 지시대로 진행해 줘. 경로는 모두 작업 폴더 기준이야.
```

헤르메스가 대응표를 먼저 보여 주면 근거를 읽어 보고 다음처럼 답합니다.

```text
확인했어. 표대로 정리해 줘. 다 끝나면 원본 12개가 그대로인지와 정리본이 원본과 내용이 같은지 확인하고, 정리 10개·중복 1개·확인 필요 1개인지 세어서 알려 줘.
```

정리가 끝나면 파일 탐색기에서 output\organized\를 열어 정리본이 날짜순으로 놓였는지 직접 봅니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| prompt.md | 정리 규칙과 진행 순서를 담은 지시문 |
| input\files\ | 정리할 원본 12개(합성 자료). 수정하지 않습니다 |
| output\organized\ | 정리본(실행하면 생깁니다). 이름순이 날짜순입니다 |
| output\source-map.json | 원래 이름·정리본·상태·근거를 담은 대응표(헤르메스가 저장) |
| expected\source-map.json | 편집한 비교용 대응표와 원본 해시 |
| reset.py | 결과 폴더(output\)를 지우는 스크립트. 앱에서는 '다시 하기'처럼 대화로 지웁니다 |

이름의 주제 부분(예: 주간회의, 할일)은 실행마다 표현이 달라도 됩니다. 종류와 주제가 알맞은지는 사람이 대응표로 판단합니다.

## 다시 하기

새 대화에서 다음처럼 부탁합니다. 받은 원본(input\)과 헤르메스 설정 폴더는 지우지 않습니다. 원본(input\files\)이 바뀌었으면 먼저 '작업 폴더의 input 폴더에서 처음 받은 상태와 달라진 파일과 새로 생긴 파일의 목록을 보여 줘. 아직 고치거나 지우지 마.'라고 부탁합니다. 목록을 보고 되돌릴 파일만 골라 '이 파일들만 받은 상태로 되돌려 줘'라고 답합니다. 내가 넣은 파일은 지워지지 않게 목록에서 빼 둡니다.

```text
작업 폴더는 홈 폴더의 team-ai-agent\code\ch02\02-organize-notes야. output 폴더의 파일 목록을 보여 주고, 내가 확인하면 지워 줘.
```
