내 업무에 쓸 에이전트 답변 규칙 초안을 정리해 줘.

my-rules.md와 헤르메스 설정 폴더의 SOUL.md(지금 내 이름과 규칙이 든 파일)를 읽고 다음 네 부분으로 나누어 SOUL.md 초안을 작성해 줘.
0. 이름과 역할(설정 폴더 SOUL.md의 지금 이름과 역할, 결과 파일 작성 표시를 그대로 유지)
1. 기본 말투와 피할 표현(과장 수식어, 근거 없는 효과 단정 금지)
2. 불확실한 내용 표시 방식(원문에 없는 수치·일정·담당자는 '미정' 또는 '[확인 필요]'로 표기)
3. 답변 구성 원칙(확인된 사실과 제안을 분리하고 사실 옆에 출처 문서 ID 표기)

초안을 먼저 화면에 보여 주고, 내가 확인하면 output\SOUL.md에 저장해 줘.
설정 폴더의 SOUL.md와 이 폴더의 my-rules.md·SOUL.md는 수정하지 마. 먼저 읽은 파일의 전체 경로를 알려 줘.
