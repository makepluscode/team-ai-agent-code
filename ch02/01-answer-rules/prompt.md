내 업무에 쓸 에이전트 답변 규칙 초안을 정리해 줘.

my-rules.md와 ~/.hermes/SOUL.md를 읽고 다음 네 부분으로 나누어 SOUL.md 초안을 작성해 줘.
0. 이름과 역할(~/.hermes/SOUL.md의 이름 자비스와 결과 파일 작성 표시를 그대로 유지)
1. 기본 말투와 피할 표현(과장 수식어, 근거 없는 효과 단정 금지)
2. 불확실한 내용 표시 방식(원문에 없는 수치·일정·담당자는 '미정' 또는 '[확인 필요]'로 표기)
3. 답변 구성 원칙(확인된 사실과 제안을 분리하고 사실 옆에 출처 문서 ID 표기)

초안을 먼저 화면에 보여 주고, 내가 확인하면 output/SOUL.md에 저장해 줘.
~/.hermes/SOUL.md와 my-rules.md는 수정하지 마.
