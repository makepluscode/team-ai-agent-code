# 6장: 업무 레시피 자동화 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: 소규모 팀의 일상 업무(고객 문의 분류, 견적서 초안 작성, 아침 브리핑 생성, 주간 보고 취합)를 예약 실행(cron) 및 템플릿 기반으로 자동화한다.
- **주요 독자 산출물**: 문의 분류기, 견적서 생성기, 아침 브리핑 수집 스크립트, 주간 보고 집계기.

## 2. 세부 기능 요구사항
1. **문의 분류 및 초안 (`src/recipes/inquiry.py`)**:
   - 들어온 문의를 4개 범주(단순상담, 기술견적, 불만접수, 파트너십)로 분류.
   - 사내 위키와 제품 FAQ를 참조하여 답장 초안을 자동 생성.
2. **견적서 초안 생성 (`src/recipes/estimate.py`)**:
   - 고객 요청 품목과 수량을 바탕으로 기본 단가표(SQLite)를 매핑하여 마크다운 견적서 서식 출력.
3. **아침 브리핑 자동 집계 (`src/recipes/briefing.py`)**:
   - 매일 오전 08:50 cron 실행: 밤사이 접수된 문의, 오늘 예정된 미팅, 긴급 처리 건을 요약하여 대시보드 1열 상단에 게시.
4. **주간 보고서 집계 (`src/recipes/weekly.py`)**:
   - 금요일 17:30 실행: 일주일간 처리된 문의 건수, 주요 회의 결정사항, 완료 과제 자동 요약.

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: 템플릿 엔진으로 Jinja2를 활용해 마크다운 및 HTML 출력을 공유 가능하게 설계한다.
- **Claude**: 특정 업종(예: 제조업, 법률)에 치우치지 않는 범용 IT/서비스 팀 기준 예제 데이터를 유지한다.
