# 7장: 완성형 팀 대시보드 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: 1장에서 예고했던 팀 대시보드 완성본을 FastAPI + HTMX로 온전히 구현한다. 실시간 상태 배지(`[로컬 LLM]`, `[상용 API]`)를 통해 처리 경로를 투명하게 노출하고, 5인 팀이 함께 쓰는 메인 허브를 완성한다.
- **주요 독자 산출물**: 완성형 팀 대시보드 웹 애플리케이션(`src/app/main.py`, `src/app/templates/dashboard.html`).

## 2. 세부 기능 요구사항
1. **헤더 및 시스템 메트릭**:
   - 시스템 상태 점(`● 온라인`), 로컬 모델 상태(`qwen3.5:9b 준비됨`), 클라우드 API 연결 상태.
   - 데이터 경로 범례: 초록색 `[🔒 로컬 LLM]`, 파란색 `[☁️ 상용 API]`.
2. **실시간 KPI 패널 (4종 카드)**:
   - 미처리 문의: `3건` (주의 태그)
   - 오늘 회의록: `2건`
   - 사내 위키 지식: `28문서`
   - 데이터 보호율: `100% (차단 14건)`
3. **업무 패널 (좌측 열)**:
   - **월요일 아침 브리핑**: 주간 중점 과제 및 긴급 문의 요약 카드.
   - **실시간 알림**: 견적 승인 대기, 회의록 자동 생성 완료 알림.
   - **최근 처리 작업 목록**: 태그별(로컬/API) 처리 내역 타임라인.
4. **에이전트 대화 및 작업 위임 (우측 열)**:
   - 실시간 챗봇 인터페이스.
   - 질의 성격에 따른 동적 배지 부여:
     - 일반 질문 → `[☁️ 상용 API]` 배지와 답변.
     - 고객 DB/계약 질문 → `[🔒 로컬 LLM]` 배지와 가명화된 안전한 조회 결과.
   - 프롬프트 추천 버튼: "오늘 미팅 요약", "미처리 문의 분류", "고객사 계약 현황".

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: HTMX의 SSE(Server-Sent Events) 또는 정주기 폴링(`hx-trigger="every 10s"`)을 선택적으로 사용하여 대시보드의 실시간성을 확보한다.
- **Claude**: 1장의 프로토타입 디자인(`dashboard_v0.html`)과 100% 동일한 색상, 여백, 타이포그래피 변수를 적용하여 일관성을 지킨다.
