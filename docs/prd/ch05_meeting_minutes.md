# 5장: 회의록 자동화 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: 회의 음성 녹음본을 대시보드에 업로드하면, 로컬 Whisper를 통해 음성을 전사하고, 로컬 LLM을 통해 결정 사항과 실행 과제(To-Do)를 구조화된 회의록으로 자동 추출한다.
- **주요 독자 산출물**: 미팅 파일 업로더, 로컬 Whisper 전사 파이프라인, 대시보드 회의록 게시판.

## 2. 세부 기능 요구사항
1. **오디오 파일 수신 및 저장**:
   - `POST /api/meeting/upload`: `.m4a`, `.mp3`, `.wav` 파일 업로드 지원.
2. **로컬 Whisper 전사 (`src/whisper/transcribe.py`)**:
   - `openai-whisper` (small 모델)를 팀 PC GPU에서 로컬 구동.
   - 음성 데이터가 외부 클라우드로 단 1바이트도 유출되지 않음.
3. **구조화된 요약 추출 (Pydantic 모델)**:
   - 전사 텍스트에서 `회의명`, `일시`, `참석자`, `논의 안건`, `결정 사항(Decisions)`, `액션 아이템(Action Items, 담당자, 마감일)`을 JSON으로 추출.
4. **대시보드 실시간 반영**:
   - 추출된 회의록 카드가 HTMX를 통해 대시보드의 '최신 회의록' 목록에 즉시 추가됨.

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: Whisper 추론 완료 후 즉시 GPU VRAM을 회수하거나 Ollama와 충돌하지 않도록 처리 파이프라인을 격리해야 한다.
- **Claude**: 외부 캘린더나 자동 녹음 봇 연동 같은 과도한 기능은 제외하고, 사용자가 파일을 드래그 앤 드롭하는 수동 업로드 방식으로 간결성을 유지한다.
