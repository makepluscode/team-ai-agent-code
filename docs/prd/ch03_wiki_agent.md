# 3장: 사내 LLM 위키 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: 마크다운 기반 사내 문서를 수집·색인하고, 에이전트가 정확한 출처(파일명, 줄 번호)와 함께 팀원의 질문에 답하는 위키 어시스턴트를 구현한다.
- **주요 독자 산출물**: 사내 위키 디렉터리 구조(`wiki/`), 마크다운 프런트매터 규격, 위키 검색 도구 및 답변 생성기.

## 2. 세부 기능 요구사항
1. **위키 데이터 구조**:
   - YAML 프런트매터(`제목`, `날짜`, `카테고리`, `태그`, `관련문서`) 필수 적용.
   - 원본 문서(`raw/`) → 정제된 위키 문서(`wiki/`) → 목차/인덱스(`index.md`) 파이프라인.
2. **검색 및 출처 추적 도구 (`src/wiki/search.py`)**:
   - 키워드 및 시맨틱 매칭으로 관련 마크다운 섹션 추출.
   - 응답 생성 시 본문 하단에 `[출처: wiki/faq.md#L15-L24]` 형식의 정확한 링크와 참조 행 번호 강제 포함.
3. **대시보드 연동**:
   - 대시보드 챗봇에서 위키 질문 시 사내 위키 도구가 활성화되며, 답변에 `[사내 위키 출처]` 배지 부여.

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: 무거운 벡터 DB(Pinecone/Chroma) 대신 로컬 파일 시스템과 SQLite FTS5(전문 검색) 또는 정규식 기반 검색기를 우선 사용하여 초보 독자의 인프라 부담을 배제한다.
- **Claude**: 환각(Hallucination) 방지를 위해 위키 문서에 없는 내용은 반드시 "사내 위키에서 해당 내용을 찾을 수 없습니다"로 답하도록 프롬프트를 제한한다.
