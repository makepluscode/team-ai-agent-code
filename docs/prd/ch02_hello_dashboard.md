# 2장: 개발 환경 및 대시보드 뼈대 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: WSL2 환경 구축, uv 기반 파이썬 의존성 관리, FastAPI + HTMX 대시보드의 최소 뼈대를 구축하고 에이전트와 첫 통신('안녕' 응답)을 완성한다.
- **주요 독자 산출물**: 웹 브라우저에서 접속 가능한 FastAPI + HTMX 기반 대시보드, 챗봇 대화 패널.

## 2. 세부 기능 요구사항
1. **백엔드 (FastAPI)**:
   - `GET /`: 대시보드 메인 템플릿 반환 (`templates/dashboard.html`).
   - `POST /api/chat`: 사용자 메시지를 수신하여 HTMX 스왑용 HTML 조각(조각 메시지) 반환.
   - 아직 로컬 모델은 탑재하지 않으며, 클라우드 API 또는 에코 모드로 응답을 반환한다.
2. **프론트엔드 (HTMX)**:
   - `hx-post="/api/chat"`, `hx-target="#chat-messages"`, `hx-swap="beforeend"`를 통해 페이지 리로드 없이 실시간 메시지 추가.
   - 메시지 전송 후 폼 자동 초기화(`hx-on::after-request="this.reset()"`).
3. **디자인 및 스타일**:
   - 외부 CDN 자바스크립트 빌드 툴 없이 단일 CSS 또는 경량 스타일시트 적용.
   - 밝은 테마 기본 유지 (도판 가이드라인 준수).

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: 2장의 코드는 7장에서 대시보드를 확장할 때 다시 작성하지 않고 모듈식으로 이어 붙일 수 있도록 `src/app/`의 베이스 구조로 삼는다.
- **Claude**: Ollama나 복잡한 모델을 2장에서 성급하게 설치하지 않고 순수 파이썬 웹 서버 띄우기에만 집중하여 초반 진입 장벽을 낮춘다.
