# 8장: 외부 누출 점검 및 감사 — 요구사항 정의서 (PRD)

## 1. 개요 및 배경
- **장 목적**: 클라우드 상용 API로 전송되는 실제 페이로드를 감사(Audit)하여, 카나리아 데이터(가짜 식별자)와 민감 정보 패턴이 실제로 누출되지 않았는지 엄격하게 검증한다.
- **주요 독자 산출물**: 카나리아 토큰 주입기, JSONL 감사 로거, 누출 점검 자동화 스크립트(`src/audit/checker.py`).

## 2. 세부 기능 요구사항
1. **카나리아 토큰 기법**:
   - 사내 DB에 고유 식별 문자열(`CANARY-UUID-SECRET`)을 심어둠.
   - 외부 API 프록시 로그에서 해당 문자열이 단 한 번이라도 검색되면 경보 발생.
2. **JSONL 감사 로거 (`src/audit/logger.py`)**:
   - 외부 API로 나가는 모든 요청(헤더, URL, 페이로드 본문)을 `logs/api_requests.jsonl`에 암호화 보존.
3. **누출 점검 검사기 (`src/audit/checker.py`)**:
   - 정규식 검사: 전화번호(`010-\d{4}-\d{4}`), 이메일, 주민번호, 원화 금액(`\d+만\s*원`) 패턴 전수 검사.
   - 0건 검출 시 `LEAK TEST PASSED` 리포트 발행.

## 3. 교차 검토 (Codex & Claude 협업 노트)
- **Codex**: 감사 로그 자체에 실제 비밀 키가 저장되지 않도록 로그 마스킹을 선행해야 한다.
- **Claude**: "남은 위험"을 함께 밝히며, 형태가 변형된 민감 정보나 은닉 프롬프트 공격에 대한 한계를 명시한다.
