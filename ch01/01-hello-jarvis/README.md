# 01-hello-jarvis: 이름 붙이기·메모리

> 이 예제는 윈도우의 헤르메스 데스크톱 앱으로 실습합니다. 예제는 홈 폴더의 team-ai-agent\code(C:\Users\로그인 이름\team-ai-agent\code)에 받고, 대화창에 넣을 문장은 [복사용 문장 모음](../../COMMANDS.md)에서 복사합니다. 헤르메스 설정 폴더는 C:\Users\로그인 이름\AppData\Local\hermes입니다.

헤르메스의 기본 규칙 파일 SOUL.md에 이름(자비스)과 역할을 적어 자기소개로 적용을 확인하고(책 1.2.2절), 메모리(USER.md·MEMORY.md)에 예제 위치와 보고 선호를 실습용 항목으로 저장해 새 대화에서 이어지는지 확인한 뒤 지웁니다(1.4절). 클로드 연결 확인 질문(question.md)도 이 폴더에 있습니다(책 사용 설명서의 '클로드 연결').

## 실행 방법

1. 이름 붙이기(1.2.2절): 새 대화에서 다음 문장을 보내고, 끝나면 새 대화를 열어 '너는 누구야? 한 문장으로 자기소개해 줘.'라고 묻습니다.

```text
작업 폴더는 홈 폴더의 team-ai-agent\code\ch01\01-hello-jarvis야. 헤르메스 설정 폴더의 SOUL.md를 이 작업 폴더의 SOUL.md 내용으로 바꿔 줘. 바꾸기 전에 설정 폴더의 SOUL.md를 설정 폴더 안에 SOUL.md.orig로 백업하고, 백업이 이미 있으면 덮어쓰지 마. 작업 폴더의 SOUL.md는 고치지 마.
```

2. 메모리(1.4절): 새 대화마다 차례로 remember.md → recall.md → forget.md를 실행합니다. remember.md와 forget.md는 '작업 폴더는 홈 폴더의 team-ai-agent\code\ch01\01-hello-jarvis야. 이 폴더의 remember.md를 읽고 그 지시대로 해 줘.'처럼 보내고, recall.md는 내용을 그대로 대화창에 붙여 넣습니다(작업 폴더를 알려 주지 않는 것이 실습의 요점입니다).
3. 저장된 기억은 파일 탐색기 주소 표시줄에 %LOCALAPPDATA%\hermes\memories를 넣고 USER.md·MEMORY.md를 메모장으로 열어 확인합니다. '기억했다'는 답만 믿지 않습니다.

- SOUL.md.orig는 이미 있으면 덮어쓰지 않으므로 처음 설치한 SOUL.md를 한 번만 보관합니다. 원래대로 되돌리려면 '헤르메스 설정 폴더의 SOUL.md를 같은 폴더의 SOUL.md.orig 내용으로 되돌려 줘.'라고 부탁하고 새 대화를 엽니다.
- 다른 이름을 쓰려면 이 폴더의 SOUL.md에서 '자비스'를 바꾼 뒤 1번을 실행합니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| SOUL.md | 이름·역할·결과 파일 작성 표시를 정하는 기본 규칙 |
| question.md | 연결 상태를 확인하는 짧은 업무 질문(사용 설명서의 '클로드 연결') |
| prompt.md | 자기소개를 요청하는 질문(1.2.2절) |
| remember.md | 보고 선호(USER.md)와 예제 위치(MEMORY.md)를 '실습용' 항목으로 저장하게 하는 지시문 |
| recall.md | 새 대화에서 기억을 말하고, 경로를 알려 주지 않은 채 1장 점검표를 찾아 기억한 선호대로 보고하게 하는 지시문 |
| forget.md | '실습용' 항목만 지우게 하는 지시문 |
| reset.py | 결과 폴더(output\)를 지우는 스크립트. 앱에서는 '다시 하기'처럼 대화로 지웁니다 |

자기소개에 자비스라는 이름과 매니저의 업무를 돕는다는 역할이 나오면 적용된 것입니다. 이 폴더에 SOUL.md가 있는 것만으로는 적용되지 않고, 헤르메스 설정 폴더의 SOUL.md를 바꿔야 헤르메스가 읽습니다. 메모리에는 API 키·비밀번호·고객 정보와 바뀌는 업무 사실을 넣지 않습니다.
