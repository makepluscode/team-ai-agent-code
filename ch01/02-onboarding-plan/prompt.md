스튜디오 메리의 첫 온보딩 계획 작업을 진행해 줘.

입력 파일은 input/DOC-001_onboarding.md야.
이 자료를 짧게 요약한 뒤 다음 다섯 항목으로 온보딩 계획을 작성해 줘.
1. 자료 요약(원본에서 확인한 준비 내용)
2. 새 팀원을 위한 온보딩 가이드(팀 소개·기본 도구 안내·자료함 규칙 공유 예정)
3. 첫 일정(잠정 일시와 첫 시간에 할 일, 정해지지 않은 세부 시간표는 '미정')
4. 매니저의 확인 항목(진행 장소·최종 검토자 등)과 제안(사실과 구별)
5. 출처(문서 ID, 문서 버전, 작성 시각, 원본 파일 경로)

파일에 없는 장소, 검토자, 확정 일정을 추측해서 채우지 말고 반드시 '미정'으로 남겨 줘.
10월 12일 10:00 일정은 확정이 아니라 '잠정'이라는 점을 그대로 유지해 줘.

입력 파일은 절대 수정하지 마.
정리한 내용은 output/DOC-005_onboarding-plan.md에 새 마크다운 파일로 저장해 줘.
같은 이름의 결과 파일이 이미 있으면 덮어쓰지 말고 멈춘 뒤 알려 줘.
저장을 마친 뒤에는 저장한 파일을 다시 읽어서 실제 파일 경로와 저장된 전체 내용을 보여 줘.
