# 개인 스킬·예약과 복구

개인 스킬·예약 실물은 personal-weekly-report/의 SKILL.md와 schedule.example.json입니다.

3장 자료: ../documents/ch03/start/skills/weekly-report/ 및 input/personal-schedule.example.json. 실행: uv run team-work schedule --help. 예약 생성만으로 상용 모델 실행이나 Hermes 등록이 이뤄지지 않습니다. run-due를 호출해야 합니다. backup/restore는 새 폴더에 보존·복구하고 파일 해시를 검사합니다. 팀 운영 예제는 ../requests/ch11~12를 사용합니다.
