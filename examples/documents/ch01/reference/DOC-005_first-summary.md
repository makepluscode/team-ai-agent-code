# 첫 온보딩 계획

> 비교용 편집 예시입니다. 실제 모델 응답이 아닙니다.

## 온보딩 가이드
첫 시간에는 팀 소개와 기본 업무 도구 안내를 받고, 이후 공유되는 자료함 이용 규칙을 읽습니다. 세부 시간표는 미정입니다.
자료함에서 이용 규칙과 지난 회고를 읽습니다. 원본은 보존하고 정리한 결과는 별도로 저장합니다. 자료 접근은 직접 열어 확인합니다.

## 첫 일정

## 준비할 일
자료 접근 확인, 원본·결과 폴더 구별, 질문 목록 작성.
