# 자료 비교표

> 비교용 편집 예시입니다. 실제 모델 응답이 아닙니다.

| 항목 | 이용 규칙 | 지난 회고 | 확인 |
|---|---|---|---|
| 원본 보존 | 원본 유지·결과 분리 | 원본 유지 제안 | 공통 |
| 이름 규칙 | 문서 종류와 버전 | 이름 불일치 관찰 | 공통 문제 대응 |
| 일정 버전 | 별도 설명 없음 | 잠정·확정 표시 제안 | 새 확정 규칙 아님 |
