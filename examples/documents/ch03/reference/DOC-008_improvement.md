# 온보딩 개선 기획 메모

> 비교용 편집 예시입니다. 실제 모델 응답이 아닙니다.

현재 사실: 자료함 규칙은 원본 보존과 문서 종류·버전을 담은 이름을 요구합니다. 안내 일정은 잠정입니다.

개선 제안: 안내에 잠정·확정 표시를 추가하고 이름 규칙을 함께 읽습니다.

확인할 점: 새 방식 적용 여부, 장소와 최종 검토자.
