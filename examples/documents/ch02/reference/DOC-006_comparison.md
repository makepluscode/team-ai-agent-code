# 두 회의 자료 비교표

> 저자 편집 비교 예시입니다. 실제 모델 응답이나 검수 완료 정답이 아닙니다.

지난주 노트는 준비 항목과 개선 의견을 남겼습니다. 이번 주 노트는 같은 안내 방향을 유지하며 자료 목록과 초안 정리 완료를 확인했습니다.

| 항목 | 지난주 | 이번 주 | 구분 |
|---|---|---|---|
| 준비 방향 | 팀 소개·도구·자료함 안내 | 같은 방향 유지 | 공통점 |
| 자료 준비 | 자료 목록 점검·초안 정리를 할 일로 둠 | ITEM-001·002 완료 | 변화 |
| 최신 경로 | 병기 의견 | 계속 검토 중 | 제안, 채택 미정 |
| 장소·최종 검토자 | 미정 | 미정 유지 | 확인 필요 |
