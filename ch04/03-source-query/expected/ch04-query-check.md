1. 새 동료 안내 일시와 장소
   - 답변: 안내 일시는 2026-10-12 10:00으로 계획돼 있으나 아직 '잠정'입니다. 안내 장소는 '미정'입니다.
   - 위키 근거: wiki/guides/onboarding.md (1. 현재 안내 일정과 조건)
   - 원본 출처: raw/DOC-001_onboarding.md (DOC-001@r1)

2. 안내자료 최종 검토자
   - 답변: 현재 '미정'입니다. 위키와 원본에 확정된 검토자가 없어 확인이 필요합니다.
   - 위키 근거: wiki/guides/onboarding.md (1. 현재 안내 일정과 조건)
   - 원본 출처: raw/DOC-001_onboarding.md (DOC-001@r1)
