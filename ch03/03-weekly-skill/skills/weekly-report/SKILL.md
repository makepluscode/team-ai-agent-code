# 주간 보고 작성

## 입력
- 실행한 폴더의 input/DOC-004_weekly-meetings.md(읽을 파일 목록)와 input/snapshot.json(관측 기간·기준 시각)
- 결과 파일 경로. 요청에 없으면 실행 전에 먼저 묻는다.

## 절차
1. DOC-004에 적힌 input/organized/의 텍스트 자료만 읽는다. 사진과 확인-필요/는 읽지 않는다.
2. 이번 주 완료를 항목키별로 중복 제거해 '관측 완료 합계'로 적고, 완료마다 근거 파일·절 또는 항목키를 붙인다. 지난주 완료와 항목키가 없는 개인 메모는 세지 않는다.
3. 지난주 대비 변화와 제안·미정을 나눈다.
4. 남은 액션 아이템을 담당·기한·상태·출처로 정리하고 없는 값은 '미정'으로 둔다.
5. 상태 미기재, 아직 없는 기간의 기록, 회신 대기를 확인할 점으로 적는다. 특정 노트의 신규 완료 0건을 주 전체 0건으로 넓히지 않는다.
6. 관측 기준 시각은 snapshot.json 값을 그대로 쓴다. 예약이나 나중 실행이어도 실행 시각으로 바꾸지 않는다.
7. 업무 TASK-001은 '확인 대기'로 둔다.
8. 60줄 안팎으로 간결하게 쓰고 결과 경로에 새 파일로 저장한 뒤 다시 읽어 보여 준다. 같은 이름의 파일이 있으면 덮어쓰지 않고 멈춘다.

## 금지
- 입력 파일 수정, 외부 전송, 개인 경로·API 키 기록
