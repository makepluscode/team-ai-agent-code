# 브랜드 용어 교정과 수정 이유 기록

고객 지침과 원문 초안을 입력으로 받습니다. 원문·수정안·수정 이유의 표를 만듭니다. 표현만 고치고 제품 사실·금액·날짜는 보존합니다. 지침에 없는 용어는 확인 필요로 남깁니다.

1. 요청의 고객과 입력 경로를 확인합니다.
2. 해당 고객의 지침과 원자료를 읽습니다.
3. 사실과 제안, 확인 필요를 구분합니다.
4. 새 파일로 저장하고 결과를 다시 읽습니다.
5. 원문·기간·수치·수정 이유를 대조합니다.

다른 고객의 사실을 섞지 않습니다. 외부 발송과 게시, 설정 변경은 별도 확인을 받습니다.
