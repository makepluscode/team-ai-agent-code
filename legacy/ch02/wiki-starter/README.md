# 스튜디오 메리 팀 위키

『팀 AI 에이전트 실전』의 팀 위키 시작 저장소입니다. 2장에서 이 폴더로 팀의 비공개 저장소를 만들고, 팀원이 각자 받아 씁니다.

- 정리 규칙: [AGENTS.md](AGENTS.md)
- 페이지 목록: [wiki/index.md](wiki/index.md)
- 정리 기록: [wiki/log.md](wiki/log.md)
- 공통 말투와 고객별 지침: [guides/](guides/)
- 팀 스킬: [skills/](skills/) — 위키 동기화 스킬([skills/wiki-sync](skills/wiki-sync/SKILL.md))이 들어 있습니다.

원본(raw/)은 넣기만 하고 고치지 않습니다. 위키 페이지(wiki/)는 위키 정리 담당자의 헤르메스가 정리합니다. 받아 오기와 올리기는 위키 동기화 스킬로 합니다.

예제의 고객사와 자료는 모두 책을 위해 만든 합성 자료입니다.
