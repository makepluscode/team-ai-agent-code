# 위키 동기화

팀 위키(Git 저장소)를 다른 팀원과 주고받는 스킬입니다. Git 명령을 직접 실행하지 않고 **반드시 `skills/wiki-sync/scripts/wiki_sync.py`만 실행합니다.** 이 실행 파일이 고른 파일만 기록하고, 문제가 생기면 멈추고, 강제로 올리지 않도록 처리합니다. 실행 파일이 종료 코드 2로 끝나면 그 자리에서 멈추고 출력 내용을 사람에게 그대로 보여 줍니다. 멈춘 상태를 스스로 풀려고 다른 Git 명령을 실행하지 않습니다.

실행 위치는 위키 폴더의 루트입니다. 실행 파일은 위키 저장소 안의 `skills/wiki-sync/scripts/wiki_sync.py`이며, 설치된 스킬 폴더가 아니라 이 경로를 씁니다. 그래야 팀원 모두가 위키와 같은 판의 실행 파일을 씁니다.

## 대화형 동기화 ("위키 동기화해 줘")

1. `python3 skills/wiki-sync/scripts/wiki_sync.py status`를 실행하고 결과를 보여 줍니다.
2. 기록하지 않은 변경이 있으면 파일 목록을 보여 주고, **올릴 파일을 사람에게 고르게 합니다.** 다음 파일은 고르기 전에 경고합니다.
   - raw/ 안에서 내용이 바뀐 파일(원본은 고치지 않는 규칙)
   - 개인 연락처·API 키처럼 보이는 내용이 든 파일
3. 기록 문구를 제안합니다. 형식은 `[이름] 무엇을 · 왜`입니다. 사람이 고치거나 승인하면 `python3 skills/wiki-sync/scripts/wiki_sync.py commit -m "<문구>" <고른 파일들>`을 실행합니다.
4. 고르지 않은 변경이 남아 있으면 받아 오기 전에 멈추고, 그 파일을 어떻게 할지(이번에 함께 기록 / 그대로 두고 다음에) 묻습니다. 그대로 둔다면 이번 동기화는 여기서 끝냅니다.
5. `python3 skills/wiki-sync/scripts/wiki_sync.py pull`로 팀 변경을 받아 와 합칩니다. 받아 온 변경 목록을 보여 줍니다.
   - 충돌로 멈추면 부딪친 파일과 두 판을 보여 주고 **어느 판을 남길지 사람에게 묻습니다.** 사람이 정한 대로 파일을 고친 뒤 3번처럼 그 파일만 기록합니다. 취소를 원하면 `abort`를 실행합니다.
6. `python3 skills/wiki-sync/scripts/wiki_sync.py push`로 올립니다. 거부되면 5번부터 다시 합니다.
7. `python3 skills/wiki-sync/scripts/wiki_sync.py soul-check`를 실행합니다. 위키의 SOUL.md가 다르면 차이를 보여 주고, 적용할지 묻습니다. 승인하면 `soul-apply`를 실행합니다(기존 파일은 날짜를 붙여 보관됩니다).

## 받기 전용 (예약 실행용, "위키 받아 와")

`python3 skills/wiki-sync/scripts/wiki_sync.py pull-only`만 실행합니다. 기록하지 않은 변경, 올리지 않은 기록, 갈라진 이력이 있으면 아무것도 바꾸지 않고 멈춥니다. 멈추면 다음 작업을 하지 않고 멈춘 이유만 결과에 남깁니다. 받기 전용에서는 기록하거나 올리지 않습니다.

## 되돌리기 ("어제 올린 ○○ 변경을 되돌려 줘")

1. `python3 skills/wiki-sync/scripts/wiki_sync.py history <파일>`로 기록을 보여 주고, 되돌릴 기록을 사람에게 확인받습니다.
2. `python3 skills/wiki-sync/scripts/wiki_sync.py revert <기록 ID>`를 실행합니다. 되돌린 사실이 새 기록으로 남습니다.
3. wiki/log.md에 되돌린 날짜와 이유를 한 줄 덧붙이고, 대화형 동기화로 올립니다.

## 하지 않는 것

- 사람이 고르지 않은 파일의 기록, 승인 없는 기록
- 강제 올리기, 이력 다시 쓰기, 충돌을 임의로 고르기
- .gitignore에 있는 파일(인증 정보·녹음 파일·실습 작업 폴더) 기록
- 이 실행 파일을 거치지 않는 Git 명령

## 알려 둘 한계

- 실행 파일은 고른 파일(폴더를 고르면 그 아래 전체) 밖의 변경을 기록하지 않지만, 고른 파일은 기록하는 순간의 내용 전체가 들어갑니다. 고른 뒤 파일을 다시 고쳤다면 목록을 다시 보여 줍니다.
- 같은 위키 폴더에서 다른 Git 작업(다른 에이전트, 편집기의 Git 기능)과 동시에 실행하지 않습니다. 검사와 기록 사이에 다른 작업이 끼면 검사한 상태와 기록하는 상태가 달라질 수 있습니다.
- Git 훅·필터·서브모듈 같은 고급 설정이 있는 저장소는 이 스킬의 보호 범위 밖입니다. 위키 시작 저장소에는 이런 설정이 없습니다.
