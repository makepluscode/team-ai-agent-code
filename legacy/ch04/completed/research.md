# 봉봉소프트 자료 조사

비교용 결과입니다. 저자가 작성했으며 모델 응답이 아닙니다.

## 질문

봉봉소프트 소개 글에서 앞세울 사용 장면 하나는 무엇인가?

## 이미 위키에 있는 내용

- 문서마다 고객·작성일·출처를 적는 조건과 제품 사실 검수 조건은 위키 리서치 페이지에 정리돼 있습니다(출처: wiki/research/content-review.md). 다시 조사하지 않았습니다.

## 자료별 관찰

| 자료 | 관찰 | 구분 |
|---|---|---|
| product.md | 문의 접수 목록과 캠페인별 진행 상태를 한곳에서 확인하는 소프트웨어 | 제품 사실 |
| REPORT-01 | 고객·작성일·출처를 적으면 다음 담당자가 자료를 구별하기 쉽다 | 외부 의견(설명용 시나리오) |
| REPORT-02 | 제품 사실과 홍보 표현을 나눠 검수한다 | 외부 의견(설명용 시나리오) |

## 제안(해석)

- 앞세울 장면 후보: 팀이 문의 목록과 캠페인 진행 상태를 같은 화면에서 확인하는 장면. 근거는 product.md의 기능 설명입니다.

## 확인 필요

- 성과 수치와 시장 규모: 자료에 없음. 확인 필요
- 채널·분량·검수 담당자: 캠페인 페이지에서 확인 필요
